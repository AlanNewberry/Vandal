# Security policy

## Supported versions

Security fixes are applied to the latest revision of the default branch. This
project is research tooling and does not currently maintain parallel release
branches.

## Reporting a vulnerability

Please do not disclose an unpatched vulnerability through a public issue.
Report it privately through the contact form at
[vandalsystems.com/contact](https://www.vandalsystems.com/contact) and include:

- the affected revision;
- reproduction steps or a minimal proof of concept;
- the expected and observed behavior;
- the potential impact;
- any suggested mitigation.

You can expect an acknowledgement within five business days. Findings made in
good faith against this repository or a local test environment are welcome.
This policy does not authorize testing against third-party systems.
